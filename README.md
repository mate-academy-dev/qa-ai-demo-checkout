# QA AI Demo Checkout

Навчальний стенд для курсу «AI-інструменти для QA», модуль про AI-тріаж
UI- та accessibility-доказів.

## НЕ ВИПРАВЛЯТИ ДЕФЕКТИ

На цій сторінці вісім навмисних дефектів доступності й верстки. Вони є
навчальним матеріалом: студенти шукають їх сканером і руками. Виправлення
будь-якого з них ламає завдання курсу.

Не запускати тут автоматичні виправлення, не додавати accessibility-лінтер
у CI, не приймати PR з правками розмітки без узгодження з автором курсу.

Карта дефектів зберігається окремо й у цей репозиторій не входить.
